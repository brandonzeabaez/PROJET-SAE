Description détaillée

Charge et résout les routes HTTP vers les contrôleurs associés.

Le fichier de configuration routes.json est analysé pour associer une URL à une classe de contrôleur, puis le bon contrôleur est instancié.

◆ loadRoute()

App\Core\Router::loadRoute ( )
private

Résout l'URL demandée et exécute l'action correspondante.

La première partie du chemin désigne le contrôleur et la deuxième désigne la méthode. Les segments restants sont transmis comme arguments. Si le contrôleur ou la méthode n'existe pas, la page 404 est affichée.
