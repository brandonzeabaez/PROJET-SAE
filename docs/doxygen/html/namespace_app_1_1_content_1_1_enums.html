enum App::Content::Enums::CountriesEnum : string

Énumération des pays disponibles dans l'application.

Chaque valeur correspond à un code ISO 3166-1 alpha-2 et est associée à un libellé lisible pour l'affichage dans le formulaire d'inscription.

Valeurs énumérées
label 

Retourne le libellé lisible associé au pays.

Renvoie
string Nom complet du pays ou son identifiant si aucun libellé n'est trouvé dans la table de correspondance.
